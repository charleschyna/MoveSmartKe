# **App Name**: MoveSmart KE Dashboard

## Core Features:

- Real-time Traffic Map: Display real-time traffic congestion on a map using Mapbox.
- KPI Cards: Display city congestion level, average trip time, and active incidents using KPI cards.
- Live AI Insights: Provide live AI insights about predicted congestion using AI as a tool.
- Route Optimization: Optimize routes between origin and destination based on traffic conditions.
- Congestion Heatmaps: Display heatmaps for congestion forecasts at 1hr, 4hr, and 24hr intervals.
- Congestion Trends: Show line charts and bar graphs displaying congestion trends by area.
- Scenario Simulation: Simulate road closure scenarios to visualize and provide projected traffic impact and suggestions from AI.

## Style Guidelines:

- Primary color: Deep Kenyan green (#14532D) to evoke natural landscapes and growth.
- Background color: Very light grayish-green (#F0F4EF) to give a clean, techy look.
- Accent color: Burnt reddish-orange (#B83322), an analogous color from the Kenyan flag to represent energy and alerts.
- Body and headline font: 'Inter' sans-serif for a modern and neutral aesthetic.
- Card-based layout for a structured and easily navigable dashboard.
- Use clear, modern icons for navigation and data visualization.
- Implement subtle animated transitions to provide smooth UX.
